# Instalação no GitHub Pages

1. Abra o repositório `Daianrj/tms-scanner`.
2. Escolha **Add file > Upload files**.
3. Envie `importador.html`, `importador.css`, `xml-app.js`, `xml-worker.js` e `db-indexed.js`.
4. Abra a pasta `vendor` do repositório e envie `jszip.min.js` e `JSZIP_LICENSE.txt`.
5. Confirme em **Commit changes**.
6. Aguarde a publicação do GitHub Pages.
7. Abra `https://daianrj.github.io/tms-scanner/importador.html`.

Depois de atualizar o Apps Script para a versão 1.9.0, o uso diário deve começar pelo botão **Abrir importador rápido do GitHub** dentro do TMS. Isso cria uma sessão segura de retorno automático; não é necessário baixar e reenviar JSON.

Não substitua o `index.html`: ele continua sendo o scanner mobile já publicado.
