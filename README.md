# Scanner NF-e — TMS Entregas

Scanner mobile estático usado pelo Controle de Entregas TMS.

## Publicação

O GitHub Pages deve publicar a branch `main` pela pasta `/ (root)`.

## Segurança

Este repositório contém somente o scanner público. Não envie para ele PINs, senhas, XMLs, dados de clientes, fotos, chaves administrativas ou código do backend do Google Apps Script.

## Recursos

- câmera traseira com foco contínuo quando disponível;
- leitura nativa com fallback para ZXing;
- validação da chave NF-e de 44 dígitos;
- Enter para confirmar e Esc para limpar;
- foto do código como contingência;
- encerramento da câmera ao sair da página para poupar bateria.
